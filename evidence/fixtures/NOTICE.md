# Fixture provenance

`acme_robotics/` is copied, unchanged, from the Ontology Quality Suite's
[`examples/acme_robotics/`](https://github.com/pwin/consolidated-ontology-quality-suite-python/tree/749af3e1be749ace3aab3ea4b492d72b3b21dbde/examples/acme_robotics)
at release 0.22.0 (the directory was last changed in commit
`9291ef452bc2cf41a019dc36fead82d97b790a2e`, 12 August 2026). It is the fixture
every command in Part III of the manual runs against. It is kept here so the
evidence can be reproduced without a checkout of the suite, because the PyPI
package does not ship its examples.
